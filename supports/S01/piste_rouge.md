# 🔴 Piste Rouge — Séance 1

## Ta mission

Écris **toi-même**, depuis un fichier vide, l'écran d'accueil de **ton** jeu XO.

## Le résultat à obtenir

```
===================================
       BIENVENUE DANS LE JEU XO
===================================
Créé par : (ton prénom)
Âge du créateur : (ton âge) ans
Prépare-toi à perdre !
```

## Ce que tu as le droit d'utiliser

Une seule commande, celle qu'on vient de voir :

```python
print("le texte que je veux afficher")
```

## Les étapes

1. Ouvre `GEEKS / mon_xo / jeu.py` dans Thonny.
2. **Efface tout** ce qu'il y a dedans.
3. Écris tes lignes, **une par ligne affichée à l'écran**.
4. Enregistre (`Fichier > Enregistrer`), **puis** lance (bouton vert ou `F5`).
5. Relance après **chaque** modification.

## Si ça ne marche pas

1. **Lis le message rouge à voix haute.** Vraiment à voix haute.
2. Compte tes guillemets : il en faut **deux** par ligne.
3. Compte tes parenthèses : une ouverte = une fermée.
4. Vérifie que `print` est **tout en minuscules**.
5. Toujours bloqué ? Demande à ton binôme, puis au binôme d'à côté. Puis 🟠.

## Quand tu as fini

- Fais lire ton écran par ton binôme : est-ce qu'il est beau ? bien aligné ?
- Puis attaque la ⚫ **piste Noire**.
