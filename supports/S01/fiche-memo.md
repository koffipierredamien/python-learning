# 🧠 Fiche mémo — Séance 1

**À garder sur la table pendant tout l'atelier. Un exemplaire par binôme.**

---

## La commande du jour

```python
print("Bonjour")
```

| Le morceau | Ce que ça veut dire |
|---|---|
| `print` | **affiche** — toujours en **minuscules** |
| `(` … `)` | ce qu'on ouvre, on le ferme |
| `"` … `"` | du texte se met **toujours** entre deux guillemets |

---

## Les 3 règles d'or

1. **L'ordinateur n'est pas intelligent. Il est obéissant.**
   Il fait *exactement* ce qui est écrit. Ni plus, ni moins.
2. **Il lit de haut en bas**, une ligne après l'autre, dans l'ordre.
3. **Le rouge n'est pas grave. Le rouge est une information.**

---

## Les 4 gestes

| Je veux… | Je fais… |
|---|---|
| lancer mon programme | le bouton vert ▶ ou la touche `F5` |
| enregistrer | `Fichier` → `Enregistrer` |
| retrouver mon fichier | `Bureau` → `GEEKS` → `mon_xo` → `jeu.py` |
| tout recommencer proprement | je recopie depuis `GEEKS` → `xo_officiel` |

---

## Les messages rouges d'aujourd'hui

| Ce que l'ordinateur écrit | Ce qu'il veut dire | Ce que je fais |
|---|---|---|
| `SyntaxError` | « Je ne comprends pas ta phrase » | Je compte mes guillemets et mes parenthèses |
| `NameError: name 'Print' is not defined` | « Je ne connais pas ce mot » | `print`, tout en minuscules |
| `EOL while scanning string literal` | « Ton texte n'est jamais refermé » | Il manque un guillemet `"` |

---

## Si je suis bloqué : **3 avant moi**

1. 👀 **Je relis** la consigne, puis le message rouge — **à voix haute**
2. 🤝 **Je demande à mon binôme**, et on regarde cette fiche
3. 👥 **On demande au binôme d'à côté** (30 secondes)

➡️ Toujours bloqué ? **Carte 🟠**

---

## Où sont les touches difficiles

| Touche | Comment la faire |
|---|---|
| `"` | `Maj` + la touche `3` *(clavier AZERTY)* |
| `(` | `Maj` + `5` |
| `)` | `Maj` + `°` |
| `#` | `AltGr` + `3` |
| `_` | `Maj` + `8` |
| `:` | `Maj` + `.` |

> Tu ne trouves pas une touche ? **Ce n'est pas une bêtise de demander.** C'est le geste n° 4 de ton Passeport Machine.
