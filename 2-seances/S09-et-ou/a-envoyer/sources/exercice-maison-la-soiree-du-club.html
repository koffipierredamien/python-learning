🧰 LA BOÎTE À OUTILS
Les deux mots de la semaine :
and → il faut TOUT
or  → il suffit d'UN
Les parenthèses, comme en maths :
(A and B) or C
on règle d'abord ce qui est dedans.
Le compteur qui MONTE :
entres = 0 au début
entres = entres + 1 à chaque entrée
La liste des fauteuils :
fauteuils = ["(libre)", "(libre)", "(libre)"]
Attention, piège : ici on écrit fauteuils[entres] sans le −1 ! Le compteur part de 0, il tombe déjà sur le bon fauteuil.
int() pour l'âge et les séances, str() pour les afficher.

4 LA RÈGLE DU CLUB — le cœur de l'exercice
Dedans, décalé de 4 espaces de plus, le if qui décide :
if (age >= 12 and age <= 18 and seances >= 3) or code == "GEEK2026": print(" ENTREZ, " + nom + " !") fauteuils[entres] = nom ← on l'assoit entres = entres + 1 ← un fauteuil de moins else: print(" Desole " + nom + ", pas ce soir.")
Lis la condition à voix haute : « (le bon âge et le bon âge et assez de séances) ou le code VIP ». Si tu sais la dire, tu sais l'écrire.

Compte les lignes que tu recopies. Note le nombre sur ta feuille et apporte-le samedi : on va le faire tomber à zéro.

⭐ SI TU AS FINI — LES BONUS
  • Le code en minuscules. Le VIP qui tape geek2026 doit entrer aussi. Un or de plus suffit.
  • Dis-lui pourquoi. Dans le refus, ajoute un if : si age < 12, affiche Trop jeune ! ; si seances < 3, affiche Viens plus souvent !
  • ⭐⭐ Déjà entré ! Un malin se représente une deuxième fois. Avant de l'asseoir :
    if nom == fauteuils[0] or nom == fauteuils[1] or nom == fauteuils[2]: print("Tu es deja a l'interieur !")
    C'est exactement le test de la case occupée du jeu XO, avec des fauteuils à la place des cases.
Quand ça marche : teste les trois situations — quelqu'un qui entre normalement, quelqu'un qu'on refuse, et un VIP de 30 ans qui entre quand même avec le code. Puis fais entrer quatre personnes valables : la quatrième doit lire Le club est COMPLET. Ctrl + S, et envoie une photo de ton écran à ton enseignant.
Les deux bugs les plus courants : un and oublié entre deux questions (Python répond SyntaxError), et entres = entres + 1 oublié — alors tout le monde s'assoit sur le fauteuil 1 et le club n'est jamais complet.
