# --- ETAPE 1 : les trois fauteuils, et le compteur -------------------
fauteuils = ["(libre)", "(libre)", "(libre)"]
entres = 0


# =====================================================================
#  VISITEUR 1
# =====================================================================
print("-" * 38)
nom = input("Qui se presente ? ")
age = input("Ton age ? ")
age = int(age)
seances = input("Combien de seances as-tu suivies ? ")
seances = int(seances)
code = input("Ton code VIP (sinon tape juste Entree) ? ")

if entres < 3:
    #  La regle du club, en une seule question :
    #     ( le bon age  ET  assez de seances )   OU   le code VIP
    #  Les parentheses, comme en maths : on fait d'abord ce qui est dedans.
    if (age >= 12 and age <= 18 and seances >= 3) or code == "GEEK2026":
        print("   ENTREZ, " + nom + " !")
        fauteuils[entres] = nom
        entres = entres + 1
    else:
        print("   Desole " + nom + ", pas ce soir.")
else:
    print("   Le club est COMPLET. Reviens samedi prochain.")

print("   Fauteuils occupes : " + str(entres) + " / 3")
print("")

⭐ Les trois bonus

1. Le code en minuscules : ... or code == "GEEK2026" or code == "geek2026":
2. Dis-lui pourquoi : deux if sans else dans le refus — on peut être trop jeune et pas assez assidu.
3. Déjà entré : if nom == fauteuils[0] or nom == fauteuils[1] or nom == fauteuils[2]: — c'est mot pour mot le test de la case occupée du jeu XO. Montrez le rapprochement : « tu viens de réécrire le cœur de notre jeu avec des fauteuils ».

✅ Les sept choses à regarder dans une copie

  • y a-t-il un and entre chaque question ? (pas une virgule)
  • les parenthèses encadrent-elles bien le groupe âge + séances ?
  • le or est-il dehors des parenthèses ?
  • entres = 0 est-il avant le premier visiteur, une seule fois ?
  • entres = entres + 1 est-il dans le if qui accepte ?
  • fauteuils[entres] — sans le −1 : ici le compteur part de 0. C'est la faute n° 1, et elle est normale : depuis trois séances on écrit case - 1. Expliquez la différence au tableau.
  • le rapport est-il dehors des blocs, collé à gauche ?
Le vrai signal de réussite : l'élève a noté combien de lignes il a recopiées (étape 5). Demandez-le en classe avant d'écrire la première boucle : c'est le meilleur argument que vous aurez.
