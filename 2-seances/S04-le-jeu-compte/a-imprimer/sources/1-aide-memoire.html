1 · Texte ou nombre ?

input rend TOUJOURS du texte. Même quand tu tapes un nombre.
🔤 Du texte → un nombreint() : traite ça comme un nombre entier. Pour calculer et pour comparer.
age = input("Ton age ? ")
age = int(age)
print(age + 10)
🔢 Un nombre → du textestr() : traite ça comme du texte. Pour coller avec +.
tour = 3
print("Tour " + str(tour))

2 · Le compteur

tour = tour + 1
Le signe = ne veut pas dire « égal ». Il veut dire « range dans ».
Cette ligne dit : range dans tour, ce qu'il y a dans tour, plus 1.
tour = 0 → une seule fois, au tout début.
tour = tour + 1 → à chaque coup accepté.
9 - tour → les cases qui restent libres.

3 · Comparer, puis décider

Comparer donne True ou False
print(5 > 3)  → True
print(5 < 3)  → False
print(5 == 5) → True
print(5 != 5) → False
Une comparaison ne donne jamais un nombre : elle donne une réponse.
⚠️ Le piège
age = 15   ← range dans
age == 15 ← est-ce égal ?
Un seul =, c'est un ordre.
Deux ==, c'est une question.

Les deux-points à la fin de la ligne du if et du else.
4 espaces de décalage : c'est eux qui disent ce qui est dans le if.
