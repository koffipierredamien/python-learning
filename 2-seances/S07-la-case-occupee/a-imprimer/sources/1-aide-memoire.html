1 · Comment savoir qu'une case est libre

Une case libre n'est pas vide : elle contient encore son numéro.
plateau[case - 1] == str(case) → True : la case est LIBRE → False : elle est PRISE
str(case) transforme le nombre 3 en texte "3", pour le comparer avec ce qu'il y a dans la case — qui est du texte.

2 · Le if dans le if

if case > 9: ····print("Cette case n'existe pas !") else: ····if plateau[case - 1] == str(case): ········plateau[case - 1] = "X" ····else: ········print("Case deja prise !")
Les décalages4 espaces pour le premier niveau, 8 espaces pour le deuxième. C'est le décalage qui dit qui est dans qui.
L'ordre des questionsLa deuxième question ne se pose que si la réponse à la première est non. On ne demande pas si la case est libre si elle n'existe pas.
