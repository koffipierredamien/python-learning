1 · Le mot du jour : elif

elif = else + if → « sinon, est-ce que… ? »
Deux if — deux questions
if note >= 10: ····print("Admis") if note >= 16: ····print("Felicitations")
Les deux peuvent s'afficher.
if / elif — un seul chemin
if note >= 16: ····print("Felicitations") elif note >= 10: ····print("Admis")
Un seul message : dès qu'un chemin passe, les autres sont sautés.

3 · L'ordre décide de tout

❌ Du plus petit au plus grand
if note >= 10: ····mention = "Passable" elif note >= 16: ····mention = "Tres bien"
note = 18 → « Passable »
✔ Du plus grand au plus petit
if note >= 16: ····mention = "Tres bien" elif note >= 10: ····mention = "Passable"
note = 18 → « Tres bien »
Python s'arrête au premier chemin qui passe. Pas au meilleur : au premier. Une cascade se lit du plus sélectif au plus large.
