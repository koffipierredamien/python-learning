✅ LE COFFRE-FORT

Le programme complet. Il tourne tel quel dans Thonny. Les messages peuvent varier d'un élève à l'autre : ce qui compte, c'est que les marques tombent dans le bon tiroir et que le score soit juste.
# --- ETAPE 1 : les cinq tiroirs, dans une liste ----------------------
tiroirs = ["1", "2", "3", "4", "5"]

print(" " + tiroirs[0] + " | " + tiroirs[1] + " | " + tiroirs[2] + " | " + tiroirs[3] + " | " + tiroirs[4])
print("")

# --- ETAPE 2 : le joueur 2 cache le tresor ---------------------------
print("Joueur 1, ferme les yeux !")
tresor = input("Joueur 2, dans quel tiroir caches-tu le tresor ? (1 a 5) ")
tresor = int(tresor)

print("")
print("=" * 34)
print("   Joueur 1, tu as 2 essais.")
print("=" * 34)
print("")

# --- ETAPE 3 : le compteur de points ---------------------------------
points = 50

# --- ETAPE 4 : premier essai -----------------------------------------
essai = input("Essai 1 - quel tiroir ouvres-tu ? ")
essai = int(essai)

if essai == tresor:
    print("   BRAVO ! Le tresor etait bien la !")
    tiroirs[essai - 1] = "T"
else:
    print("   Vide ! Ce tiroir ne contenait rien.")
    tiroirs[essai - 1] = "X"
    points = points - 20

print("")
print(" " + tiroirs[0] + " | " + tiroirs[1] + " | " + tiroirs[2] + " | " + tiroirs[3] + " | " + tiroirs[4])
print("")

# --- ETAPE 5 : deuxieme essai  (on recopie l'etape 4) ----------------
essai = input("Essai 2 - quel tiroir ouvres-tu ? ")
essai = int(essai)

if essai == tresor:
    print("   BRAVO ! Le tresor etait bien la !")
    tiroirs[essai - 1] = "T"
else:
    print("   Vide ! Ce tiroir ne contenait rien.")
    tiroirs[essai - 1] = "X"
    points = points - 20

print("")
print(" " + tiroirs[0] + " | " + tiroirs[1] + " | " + tiroirs[2] + " | " + tiroirs[3] + " | " + tiroirs[4])
print("")

# --- ETAPE 6 : le verdict --------------------------------------------
print("=" * 34)
print("Le tresor etait dans le tiroir " + str(tresor) + ".")
print("Ton score : " + str(points) + " / 50")

if points > 20:

else:
    print("Le coffre a resiste... pour cette fois.")

⭐ Les deux bonus

1. Le troisième essai : recopier le bloc de l'étape 5. Rien de plus.
2. Le tiroir déjà ouvert : avant d'ouvrir, vérifier que le tiroir contient encore son numéro — if tiroirs[essai - 1] == str(essai): … else: print("Tu as deja ouvert ce tiroir !"). C'est exactement le test de la case libre de la séance 7 : l'élève qui le réussit arrive samedi avec une séance d'avance — dites-le-lui devant la classe.

✅ Les six choses à regarder dans une copie

  • la liste a-t-elle bien cinq cases, entre crochets, séparées par des virgules ?
  • l'affichage utilise-t-il tiroirs[0] à tiroirs[4] — et pas [1] à [5] ?
  • le - 1 est-il présent dans tiroirs[essai - 1] ?
  • points = 50 est-il avant les essais, et une seule fois ?
  • points = points - 20 est-il dans le else, donc décalé ?
  • les str() sont-ils là dans le verdict ?
Barème conseillé : les étapes 1 à 3 = « il a compris la liste ». Les étapes 4 à 6 = « il a compris l'indice ». On note la preuve, pas la perfection : un jeu qui marche avec deux fautes d'orthographe dans les messages vaut mieux qu'un code parfait qui ne tourne pas.
