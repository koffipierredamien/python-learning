✅ LA BATAILLE NAVALE

Le programme complet. Les tirs 2, 3 et 4 sont le bloc du tir 1, recopié tel quel : il n'est imprimé qu'une fois ici, mais il doit apparaître quatre fois dans le fichier de l'élève.

# --- ETAPE 1 : la mer, huit cases ------------------------------------
mer = ["1", "2", "3", "4", "5", "6", "7", "8"]

print(" " + mer[0] + " | " + mer[1] + " | " + mer[2] + " | " + mer[3] + " | " + mer[4] + " | " + mer[5] + " | " + mer[6] + " | " + mer[7])
print("")


# --- ETAPE 2 : le joueur 2 place ses trois bateaux -------------------
print("Joueur 1, ferme les yeux !")
print("")

b1 = input("Joueur 2, premier bateau  (1 a 8) ? ")
b1 = int(b1)
b2 = input("Joueur 2, deuxieme bateau (1 a 8) ? ")
b2 = int(b2)
b3 = input("Joueur 2, troisieme bateau (1 a 8) ? ")
b3 = int(b3)

print("")
print("=" * 40)
print("   Joueur 1, tu peux regarder !")
print("   3 bateaux caches. Tu as 4 tirs.")
print("=" * 40)
print("")


# --- ETAPE 3 : les deux compteurs ------------------------------------
score = 0
touches = 0


# --- ETAPE 4 : LE TIR N 1  (le bloc a recopier) ----------------------
tir = input("Tir 1 - quelle case ? ")
tir = int(tir)

#  La boite temoin : on la remet a 0 AVANT les trois questions.
touche = 0

if tir == b1:
    touche = 1
if tir == b2:
    touche = 1
if tir == b3:
    touche = 1

if touche == 1:
    print("   TOUCHE ! Un bateau coule.")
    mer[tir - 1] = "X"
    score = score + 30
    touches = touches + 1
else:
    print("   PLOUF ! Rien que de l'eau.")
    mer[tir - 1] = "o"
    score = score - 10

print("")
print(" " + mer[0] + " | " + mer[1] + " | " + mer[2] + " | " + mer[3] + " | " + mer[4] + " | " + mer[5] + " | " + mer[6] + " | " + mer[7])
print(" Score : " + str(score) + "   Bateaux coules : " + str(touches) + " / 3")
print("")

⭐ Les trois bonus

1. Un cinquième tir : recopier le bloc. Le chiffre de lignes recopiées est à réclamer : il resservira à la séance 10.
2. La précision : rates = 4 - touches, puis un str() pour l'afficher.
3. Le tir déjà joué : if mer[tir - 1] == str(tir): — c'est mot pour mot le test de la case libre de la séance 7. L'élève qui le réussit arrive samedi avec une séance d'avance : faites-le expliquer au tableau par lui.

✅ Les sept choses à regarder dans une copie

  • la liste a-t-elle huit cases, et l'affichage va-t-il de mer[0] à mer[7] ?
  • le - 1 est-il présent dans mer[tir - 1] ?
  • LA FAUTE N° 1 — et c'est elle qu'on vient chercher : touche = 0 doit être remis à zéro dans chaque bloc de tir. Écrit une seule fois tout en haut, l'élève devient amiral sans rien couler. Ne le dites pas : faites-lui jouer une partie et constater.
  • les trois if sont-ils indépendants, collés à gauche l'un sous l'autre — et non imbriqués ?
  • score et touches sont-ils créés une seule fois, avant le tir 1 ?
  • touches = touches + 1 est-il dans le if, et pas dans le else ?
  • les deux verdicts de la fin sont-ils séparés ?
À qui le donner. C'est l'exercice de ceux qui ont fini Le Coffre-Fort en vingt minutes, ou qui l'avaient déjà fait. On ne donne pas les deux : un seul exercice par élève, et les autres gardent Le Coffre-Fort. La boîte à outils est exactement la même : aucune notion nouvelle, seulement un assemblage plus exigeant.
