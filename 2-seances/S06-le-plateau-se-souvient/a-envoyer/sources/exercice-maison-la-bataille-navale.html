🚢 LA BATAILLE NAVALE

La version difficile de la semaine, avec exactement les mêmes outils que Le Coffre-Fort — pas une notion de plus. Huit cases, trois bateaux cachés, quatre tirs, et une idée neuve : une boîte témoin qui retient ce qui vient de se passer.
Thonny → Fichier → Nouveau → Enregistrer sous : navale_tonprenom.py
🎯 La règle du jeu : joueur 2 cache trois bateaux dans trois cases différentes, de 1 à 8. Joueur 1 a quatre tirs. Un bateau touché vaut +30, un tir dans l'eau coûte −10. La mer garde la trace : X pour un bateau coulé, o pour un trou dans l'eau.

🧰 LA BOÎTE À OUTILS
La mer, c'est une liste de HUIT :
mer = ["1", "2", ..., "8"]
donc les indices vont de 0 à 7.
Marquer une case :
mer[tir - 1] = "X"
🆕 LA BOÎTE TÉMOIN. Elle retient si quelque chose s'est passé :
touche = 0  avant de poser les questions
touche = 1  si on a trouvé un bateau
puis if touche == 1: pour décider.
Trois if à la suite, collés à gauche l'un sous l'autre. Ils ne s'empêchent pas : Python les lit tous les trois.
DEUX compteurs qui avancent ensemble :
score = score + 30 ou score = score - 10
touches = touches + 1
int() pour les cases, str() pour les afficher.
1 LA MER
  • Affiche un cadre de 40 signes = et le titre.
  • Crée la liste mer avec les huit numéros, entre guillemets.
  • Affiche la ligne de mer. Elle est longue : écris-la une fois, puis copier-coller — tu en auras besoin cinq fois.
    print(" " + mer[0] + " | " + mer[1] + " | " + ... jusqu'à ... + mer[7])
2 LES TROIS BATEAUX
  • Affiche Joueur 1, ferme les yeux !
  • Trois questions au joueur 2, rangées dans b1, b2 et b3 — et trois int(), un par bateau.
  • Affiche le cadre 3 bateaux caches. Tu as 4 tirs.
On fait confiance au joueur 2 : il doit choisir trois cases différentes. Vérifier ça, on saura le faire dans trois semaines.
3 LES DEUX COMPTEURS
score à 0, et touches à 0. Une seule fois chacun, avant le premier tir.
Pourquoi deux ? Parce qu'ils ne disent pas la même chose : l'un mesure l'adresse, l'autre dit si la mission est remplie.

4 LE TIR N° 1 — tout l'exercice est là
Demande la case, transforme-la en nombre, puis :
touche = 0 ← la boîte témoin, remise à zéro if tir == b1: touche = 1 if tir == b2: touche = 1 if tir == b3: touche = 1 ← trois if, collés à gauche if touche == 1: print(" TOUCHE ! Un bateau coule.") mer[tir - 1] = "X" score = score + 30 touches = touches + 1 else: print(" PLOUF ! Rien que de l'eau.") mer[tir - 1] = "o" score = score - 10
Puis réaffiche la mer, le score et le nombre de bateaux coulés.
Lis le bloc à voix haute : « je ne sais rien (0) → je pose mes trois questions → je regarde ce que la boîte retient → je décide. » Si tu sais le dire, tu sais l'écrire.
5 LES TIRS N° 2, 3 ET 4
Recopie tout le bloc de l'étape 4, trois fois de plus. Tu ne changes que le numéro dans la question (Tir 2, Tir 3, Tir 4).
⚠️ Le piège de l'exercice : la ligne touche = 0 doit être dans chaque bloc. Si tu ne l'écris qu'une seule fois tout en haut, alors dès que tu touches un bateau, tous les tirs suivants seront comptés comme touchés — et tu finiras amiral sans rien avoir coulé. Teste-le exprès, pour voir.
6 LES DEUX VERDICTS
  • Affiche où étaient les trois bateaux, et le score final — il faudra str().
  • Premier verdict — la mission : si touches == 3, FLOTTE COULEE. Tu es AMIRAL ! sinon Il reste des bateaux a flot...
  • Deuxième verdict — le tir : si score >= 60, Score de professionnel. sinon Le tir demande de l'entrainement.
Les deux sont indépendants : deux if / else l'un sous l'autre, collés à gauche. Pas l'un dans l'autre.
⭐ SI TU AS FINI — LES BONUS
  • Un cinquième tir. Recopie encore le bloc. Compte les lignes que tu recopies et note le nombre sur ta feuille : on te le demandera.
  • La précision. Avant le verdict, affiche le nombre de tirs ratés : rates = 4 - touches
  • ⭐⭐ Le tir déjà joué. Retirer au même endroit ne devrait pas rapporter 30 points une deuxième fois. Une case où personne n'a encore tiré contient encore son numéro :
    if mer[tir - 1] == str(tir): ... tout le bloc du tir ... else: print("Tu as deja tire la !")
    Celui qui réussit ce bonus a déjà compris la séance de samedi prochain.
Quand ça marche : joue trois parties — une où tu coules tout, une où tu raterais tout (le score doit tomber à −40), et une où tu tires deux fois au même endroit pour voir ce que fait ton programme. Puis Ctrl + S, et envoie une photo de ton écran.
Les deux bugs les plus courants : touche = 0 écrit une seule fois tout en haut au lieu d'être dans chaque bloc — et mer[tir] sans le - 1, qui marque la case d'à côté sans que Python ne dise rien.
