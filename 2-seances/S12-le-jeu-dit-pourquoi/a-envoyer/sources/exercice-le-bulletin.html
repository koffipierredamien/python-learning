🧰 LA BOÎTE À OUTILS
La cascade : un seul chemin.
if moyenne >= 16:
elif moyenne >= 14:
else:
elif = else + if → « sinon, est-ce que… ? »
Python s'arrête au premier chemin qui passe. Pas au meilleur : au premier.
L'ordre décide de tout.
Du plus exigeant au moins exigeant.
Dans l'autre sens, tout le monde est PASSABLE.
input rend TOUJOURS du texte.
Pour calculer : note1 = int(note1)
Pour coller dans une phrase : str(moyenne)
La moyenne, sans virgule :
moyenne = int((n1 + n2 + n3) / 3)

3 LA MOYENNE
moyenne = int((note1 + note2 + note3) / 3)
Les parenthèses autour de l'addition : sans elles, Python ne divise que la dernière note. Le int() autour coupe ce qu'il y a après la virgule — un bulletin n'affiche pas 14.333333.
4 LA CASCADE — le cœur de l'exercice
Recopie ton algorithme de l'étape 0, en Python :
if moyenne >= 16: mention = "TRES BIEN" elif moyenne >= 14: mention = "BIEN" ... à toi les deux chemins du milieu ... else: mention = "A REVOIR"
  • Un seul if au départ, puis des elif.
  • Du plus grand au plus petit. Essaie une fois dans l'autre sens, avec une moyenne de 18 : tu verras s'afficher PASSABLE. C'est normal, et c'est toute la leçon.
  • Le else final n'a pas de condition : c'est « dans tous les autres cas ».
5 LE BULLETIN
  • Une ligne par matière : " Maths : " + str(note1) + " / 20"
  • Une ligne de 38 tirets - pour séparer.
  • " Moyenne : " + str(moyenne) + " / 20"
  • " Mention : " + mention — celui-là est déjà du texte, pas de str().
Astuce : print("=" * 38) écrit 38 fois le signe = sans les taper un par un.

Les deux bugs les plus courants : un int() oublié (Python colle les notes au lieu de les additionner), et la cascade à l'envers (tout le monde est PASSABLE). Le deuxième ne fait aucune erreur rouge : c'est à toi de le voir.
