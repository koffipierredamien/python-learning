# --- ETAPE 1 : la machine -------------------------------------------
#  Deux listes qui vont ensemble :
#  le produit numero 1 est produits[0], et il coute prix[0].
produits = ["Chips", "Jus", "Chocolat", "Gateau"]
prix = [100, 150, 200, 250]

# --- ETAPE 2 : le client --------------------------------------------
argent = input("Combien as-tu d'argent ? ")
argent = int(argent)

achats = 0

# --- ETAPE 3 : LA BOUCLE --------------------------------------------
#  Tant qu'il reste de quoi acheter le moins cher (100)
#  ET qu'il reste au moins un produit dans la machine.
while argent >= 100 and achats < 4:

    print("")
    print("-" * 40)
    print(" 1. " + produits[0] + " - " + str(prix[0]) + " F")
    print(" 2. " + produits[1] + " - " + str(prix[1]) + " F")
    print(" 3. " + produits[2] + " - " + str(prix[2]) + " F")
    print(" 4. " + produits[3] + " - " + str(prix[3]) + " F")
    print("-" * 40)
    print(" Tu as " + str(argent) + " F.")

    choix = input(" Ton choix (1 a 4) ? ")
    choix = int(choix)

    #  Une seule question, quatre conditions :
    #  le numero existe, le produit est encore la, et tu as de quoi payer.
    if choix >= 1 and choix <= 4 and produits[choix - 1] != "EPUISE" and prix[choix - 1] <= argent:
        print("")
        print("   CLONK !  " + produits[choix - 1] + " tombe dans le bac.")
        argent = argent - prix[choix - 1]
        produits[choix - 1] = "EPUISE"
        achats = achats + 1
    else:
        print("")
        print("   BZZZT !  Impossible : mauvais numero, produit epuise,")
        print("            ou pas assez d'argent.")

⭐ Les trois bonus

1. Ce qui manque : str(prix[choix - 1] - argent) dans le refus.
2. Le bouton SORTIE : choix = 1 avant la boucle, puis and choix != 0 dans la condition. L'élève qui oublie l'initialisation récolte un NameError : c'est une excellente leçon, laissez-la arriver.
3. Le cinquième produit : 4 lignes à changer. Faites-les compter — puis demandez combien il en aurait fallu dans la version « recopiée » de la semaine dernière.

✅ Les six choses à regarder dans une copie

  • les deux points à la fin de la ligne while ?
  • tout ce qui doit se répéter est-il décalé sous le while ?
  • argent = argent - prix[choix - 1] est-il dans le if qui vend ? (sinon la machine fait payer sans rien donner)
  • achats = achats + 1 est-il là ? Sans lui : boucle infinie.
  • le - 1 est-il présent dans les deux listes ?
  • le ticket est-il dehors de la boucle, collé à gauche ?
Si un élève arrive avec une boucle infinie : ne corrigez pas tout de suite. Lancez-la, laissez défiler, puis Ctrl + C devant tout le monde, et demandez à la classe « qu'est-ce qui ne change jamais ? ». C'est la leçon la plus rentable de la séance 11.
