La leçon du jour : la boîte, et la question

nom = input("Comment t'appelles-tu ? ")
nom — c'est une boîte avec une étiquette. Ce que le joueur tape est rangé dedans.
input — ça veut dire DEMANDE. Le programme s'arrête, il attend, il range la réponse.
" " — les guillemets vont par deux, comme des chaussures. Ce qui est dedans s'affiche tel quel.
print("Bonjour " + nom + " !")
Le + colle les morceaux bout à bout. Garde l'espace après Bonjour, sinon tout se colle.
nom sans guillemets → il affiche ce qu'il y a dans la boîte.
"nom" avec guillemets → il affiche le mot nom. Toute la différence est là.

Si l'écran devient rouge — ce n'est pas grave

Le rouge n'est pas une punition. Le rouge est une information : l'ordinateur explique ce qu'il n'a pas compris.
