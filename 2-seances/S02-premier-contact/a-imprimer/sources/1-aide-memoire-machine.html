1 · AFFICHER quelque chose

print("Bonjour")
print — ça veut dire AFFICHE. Toujours en minuscules. Ça n'imprime rien sur du papier.
( ) — une parenthèse ouverte se referme toujours.
" " — les guillemets vont par deux, comme des chaussures. Ils ne s'affichent pas : ils disent « ceci est du texte ».
Il lit ton programme de haut en bas, ligne par ligne, toujours. Si ça s'affiche dans le désordre, c'est l'ordre de tes lignes.

2 · DEMANDER quelque chose au joueur

nom = input("Comment t'appelles-tu ? ")
nom — c'est une boîte avec une étiquette. Ce que le joueur tape est rangé dedans.
input — ça veut dire DEMANDE. Le programme s'arrête, il attend, il range la réponse.
nom sans guillemets → ce qu'il y a dans la boîte. "nom" avec guillemets → le mot nom. Toute la différence est là.
print("Bonjour " + nom + " !")
Le + colle les morceaux bout à bout.
Garde l'espace après Bonjour — sinon ça donne BonjourDamien.
Ton fichier est en deux parties : la 1 maintenant, la 2 quand le professeur le dira.

Si l'écran devient rouge — ce n'est pas grave

Le rouge n'est pas une punition. Le rouge est une information : l'ordinateur explique ce qu'il n'a pas compris.
