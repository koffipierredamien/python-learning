# 🖨️ Dossier d'impression — Séance 1

Chaque document est un **fichier HTML autonome**, déjà réglé au bon format de papier.

### Comment imprimer

1. Double-cliquez sur le fichier → il s'ouvre dans votre navigateur (Chrome, Edge, Firefox).
2. `Ctrl + P` (ou `Cmd + P` sur Mac).
3. Vérifiez le **format de papier** indiqué dans le tableau ci-dessous, et l'orientation.
4. Cochez **« Graphiques d'arrière-plan »** / *Background graphics* — sinon les couleurs et les cadres ne sortent pas.
5. Marges : **par défaut** (elles sont déjà définies dans le fichier).

> 💡 Le petit encadré en pointillés en haut de chaque document est une **note pour vous** : il ne s'imprime pas.
>
> 💡 Pas d'imprimante A3 ? Imprimez en A4 avec l'option « Ajuster à la page ». Les affiches restent lisibles ;
> pour le Mur de Mission, imprimez en A3 et collez-le sur une grande feuille kraft.
>
> 💡 Pour obtenir un PDF (à envoyer, ou à faire imprimer en boutique) : dans la fenêtre d'impression,
> choisissez « Enregistrer au format PDF » comme destination.

## Matériel à acheter (non imprimable)

- Post-it : **2 par élève et par séance** — prévoir large
- Feutres noirs à pointe large (pour les étiquettes prénoms et les affiches à compléter)
- Autocollants / gommettes de couleur → servent de **badges** (une couleur par badge)
- Papier épais 160 g pour les cartes de signalisation, ou pochettes de plastification
- Ruban adhésif ou porte-badges pour les étiquettes
- Un minuteur visible de toute la salle (ou un chronomètre projeté)
- Une boîte / un bocal pour les post-it de sortie
- Une clé USB (voir [`cle-usb/`](../cle-usb/))
